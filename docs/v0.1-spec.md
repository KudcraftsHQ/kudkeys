# Kud Keys v0.1 — build spec

Shared contract for everyone working on v0.1. Hammas uses this himself, on his own Android phone, instead of
SwiftKey (which often fails to appear when a text field is tapped). Personal use, public GPL repo.

## What v0.1 is

A HeliBoard fork (GPL-3.0, https://github.com/Helium314/HeliBoard) in `android/` with:

1. **SwiftKey's key layout, copied for muscle memory.** Reference screenshot (SwiftKey in WhatsApp, dark):
   `/Users/hammashamzah/.t3/userdata/attachments/d73f4e9d-6f0d-4518-9f8e-277bbba5fb90-ca970334-31ce-4787-9577-c5bbed5fa033.jpg`.
   What it shows: **borderless keys** (plain light-grey letters on a near-black background, no key
   shapes, no number hints on the letter keys); row 2 (A–L) indented half a key on both sides; shift and
   backspace 1.5 keys wide; bottom row `123` · emoji · `,` (small mic hint above it) · space · `.` (small
   `,!?` hint above it) · enter. Match row heights, key widths/offsets and text sizes to the screenshot.
2. **Two languages, en + id, typed together** (multilingual typing, no switching needed). The space bar
   reads `‹   en/id   ›` in muted grey, exactly like the screenshot. Indonesian + English dictionaries.
3. **Removed:** gesture/swipe typing (remove the code path and the setting, not just off), the clipboard
   history UI/toolbar key, the stock toolbar keys. No account, info, "more" buttons.
4. **Toolbar (top bar): exactly three icons.** ✦ **Fix** on the far left; **Instruct** and **Mic** on the far
   right, Mic outermost (Hammas is right-handed). Fix and Instruct are placeholders in v0.1: tapping shows a
   short toast "Coming soon". The middle of the bar is empty except for:
   - the **Private** pill (amber, small, centred) when the current field is private (see 5);
   - live voice text in quick voice mode (see 6);
   - HeliBoard's suggestion strip when typing (suggestions stay — they are needed).
   Decide sensibly how suggestions and the icons share the bar; the icons must never move.
5. **Privacy.** Learn nothing (no user-dictionary additions, no history/personalization, no suggestions
   learned) when ANY of:
   - `EditorInfo.imeOptions` has `IME_FLAG_NO_PERSONALIZED_LEARNING` (Chrome incognito sets it);
   - the field is a password (all `TYPE_TEXT_VARIATION_*PASSWORD`, `TYPE_NUMBER_VARIATION_PASSWORD`);
   - it is a URL field (`TYPE_TEXT_VARIATION_URI`);
   - it is a search field: `IME_ACTION_SEARCH`, or `TYPE_TEXT_VARIATION_FILTER`, or the host app is a
     launcher (Nova: `com.teslacoilsw.launcher`; include the default-launcher package found via
     `PackageManager` HOME intent).
   Show the amber **Private** pill whenever this is true. Voice in a private field still works, and its
   `start` message sets `"private": true`.
6. **Quick voice mode (WhatsApp-style).** Hold Mic → recording starts (haptic tick), the bar shows a red
   dot, elapsed time and the live transcript; the keys stay visible. Release → insert the text into the field
   (with a leading space when needed). Slide left past a threshold → cancel (nothing inserted, "Slide to
   cancel" hint visible while holding). Slide up → lock: recording continues hands-free and a **stop** button
   appears in the exact spot of the Mic icon; tapping it inserts. A short tap on Mic (no hold) is reserved for
   full voice mode (v0.2) — in v0.1 a tap shows the hint "Hold to talk". Microphone permission: if missing,
   open a small permission activity on first use.
7. **Voice server client.** Speaks the protocol in `server/README.md` (Stream protocol section) to
   `wss://keys.kudcrafts.com/v1/stream` with `Authorization: Bearer <token>`. 16 kHz PCM16 mono, ~100 ms
   frames. Languages `["id","en"]`. Text arrives per phrase (`final` messages, placed by `segment`);
   show finals as they come, insert all on release/stop after `done` (or after a 5 s timeout, insert what is
   there). Errors show briefly in the bar ("Voice: no connection", "Voice: token rejected").
   **The token is never in the APK** (the repo is public). Settings → Voice has two fields: Server URL
   (default above) and Token (password field, stored in app-private prefs). Until a token is set, holding
   Mic shows "Set your voice token in settings".
8. **Package / naming:** applicationId `com.kudcrafts.kudkeys`, app label "Kud Keys", IME label "Kud Keys".
   Keep HeliBoard's GPL notice and credit in the About screen and README.
9. **Release:** like kud-widgets (`~/Projects/kud-widgets/.github/workflows/release.yaml`). Tags
   `v<maj>.<min>.<patch>` → signed release APK `kudkeys-<tag>.apk` + `SHA256SUMS` on the GitHub Release;
   tags with `-` are prereleases. Secrets `KC_KEYSTORE_BASE64`, `KC_KEYSTORE_PASSWORD`, `KC_KEY_ALIAS`,
   `KC_KEY_PASSWORD` are already set on KudcraftsHQ/kudkeys. Refuse to publish unsigned. PRs/pushes: unit
   tests + debug build.

## Out of scope for v0.1

Full voice mode (dictation editor, tidy, low-confidence questions), Fix/Instruct AI, clipboard, themes
beyond the one dark theme, swipe typing.

## Working rules

- Build env: `source ~/.config/android-env.sh` (JDK 17, SDK at `~/Android/Sdk`; install missing SDK parts
  with `sdkmanager`). No emulator on this machine (no KVM). Verify UI with Robolectric screenshot tests
  (`@GraphicsMode(NATIVE)`) that write PNGs you then look at.
- The machine has 16 GB RAM and other agents build in parallel: run Gradle with
  `--max-workers=2 -Dorg.gradle.jvmargs=-Xmx2g` and stop daemons when done (`./gradlew --stop`).
- Scratch files under `$TMPDIR`, never `/tmp`. Never print the token or signing secrets.
- Commit small, push your branch, open a PR against the branch you were told to base on. Never merge.
